# Prisma 7 estável — Correção do spike do Dia 2

## Objetivo e isolamento

Substituir a toolchain Prisma 8 RC pela linha estável sem implementar o
Catálogo. O spike usa apenas PostgreSQL 17 local em
`127.0.0.1:55432/plus_store_day2_prisma7_spike`. O script rejeita hosts remotos
e qualquer outro database.

Overrides validados: `deepmerge-ts 8.0.0`, `lodash 4.18.1`, `mysql2 3.23.1` e
`pg 8.23.0`.

## Migration revisada

- criada com `prisma migrate dev --create-only`;
- revisada antes do deploy;
- usa `BIGINT GENERATED BY DEFAULT AS IDENTITY`;
- usa nomes snake_case;
- cria unique de e-mail, FK e índice explícito da FK;
- aplicada somente no database isolado;
- `prisma migrate status` confirmou schema atualizado.
